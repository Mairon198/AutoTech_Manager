# AutoTech Manager

Sistema de gestión para el taller mecánico **AutoTech Solutions**.
Examen Segundo Parcial – Programación Avanzada II (Java).

## Tecnologías
- Java (Maven, NetBeans)
- Swing (interfaz gráfica)
- JDBC + SQL Server

## Estructura
```
com.autotech
├── modelo        → entidades y enums
├── dao           → interfaces de persistencia
│   └── impl      → implementaciones JDBC
├── negocio       → reglas de negocio y transacciones
├── excepciones   → excepciones personalizadas
├── hilos         → procesamiento concurrente
├── util          → conexión, validadores
└── vista         → formularios Swing
```
